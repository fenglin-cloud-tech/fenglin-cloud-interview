## 二、技术架构

```
React 18 + TypeScript + Vite 6  ──/api──▶  Express 4（Node 20）
手写 CSS（云海靛青，无 UI 库）              ├─ 智谱 glm-4-air（文本）/ glm-4v-flash（图片）
                                             └─ SQLite（sql.js / WASM）
生产：同一进程托管 dist/ 静态文件与 /api，单端口 8000
```

- **前端**：React Router 6 单页应用；设计 token 集中在 `src/styles.css`（云海靛青配色、宋体标题）；桌面优先，1180 / 980 / 640 三档响应式，手机宽度无横向溢出；PDF 文字层由 pdf.js（pdfjs-dist）在浏览器本地抽取。
- **后端**：Express + TypeScript，按 core / ai / interview / review / backup 拆分路由；统一 `HttpError` 与错误中间件，异常不会让页面白屏。
- **数据层**：SQLite 表结构覆盖 `profile`、`job`、`resume`、`jd_analysis`、`interview`、`interview_turn`、`review`、`bank_item`、`review_task`、`demo_seed`、`setting`。公网运行时用 **sql.js（SQLite 的 WebAssembly 版）**，原因见部署说明；写入后 150ms 防抖落盘，先写临时文件再原子替换。
- **模型调用**：只走服务端 `ZHIPU_API_KEY`；文本用 `glm-4-air`，简历图片用 `glm-4v-flash`（对象/数组字段先归一化为文本再校验）；请求 `response_format=json_object`；zod 校验 + 最多 3 次重试（把解析/结构错误回灌纠错）；单次超时 55 秒。图片只在内存转发，不落盘。
- **降级**：JD 匹配、面试出题、单题反馈、面试报告在模型不可用时切本地规则并标注「本地降级」；简历建议与多轮迭代没有可靠的本地等价物，返回 503 结构化错误由页面提示重试。

## 三、启动方式（两种）

### 方式 A：开发模式（前后端一起起）

```bash
cd e:\Trae\fenglin-cloud-interview\app
npm install
copy .env.example .env        # Windows；macOS/Linux 用 cp
# 在 .env 里填 ZHIPU_API_KEY=你的智谱 Key
npm run dev
```

- 前端：http://localhost:5173
- 后端：http://localhost:8787（Vite 已把 `/api` 代理到 8787）
- 数据库：`app/data/fenglin.sqlite`，**持久保存**

### 方式 B：生产模式（单进程）

```bash
cd e:\Trae\fenglin-cloud-interview\app
npm install
npm run build                 # 产出 dist/（前端）与 dist-server/（后端）
set NODE_ENV=production       # PowerShell: $env:NODE_ENV='production'
set PORT=8787
npm start                     # node dist-server/index.js
```

打开 http://localhost:8787 即可，静态文件与 API 同端口。生产模式默认把数据库写到 `%TMPDIR%\fenglin-cloud-interview\fenglin.sqlite`（可用 `DB_PATH` 覆盖），这是为无状态托管环境准备的；本地想持久化就显式设置 `DB_PATH`。

### 环境变量

| 变量 | 必填 | 说明 |
|---|---|---|
| `ZHIPU_API_KEY` | 是 | 智谱开放平台 Key，**只在服务端读取**，`.env` 已加入 `.gitignore` |
| `ZHIPU_MODEL` | 否 | 默认 `glm-4-air`（实测出题 1–7s、单题反馈 5–17s、建议与报告 8–30s；思考型模型会超时，故不选） |
| `PORT` | 否 | 默认 8787；公网部署由 `run.sh` 显式设为 8000 |
| `DB_PATH` | 否 | 覆盖数据库文件路径 |
| `STATIC_DIR` | 否 | 覆盖前端静态目录（一般不用） |
| `SHARED_DEMO` | 否 | 置 `1` 时页面顶部显示「公网演示实例」提示条 |
| `AI_RATE_LIMIT_PER_MIN` | 否 | 单个 IP 每分钟 AI 请求上限，默认 6；`0` 表示不限 |
| `AI_DAILY_LIMIT` | 否 | 单实例每日 AI 请求总量上限，默认 300；`0` 表示不限 |

**密钥安全**：Key 只出现在服务端环境变量与本地 `.env`；前端打包产物、接口响应、日志中都不会出现（日志只打印长度与前缀）。已对线上 JS 产物做过字符串检查。

## 五、已知限制（不粉饰）

1. **不做注册 / 登录**：托管平台没有持久化存储卷或外部数据库，账号与数据会在实例重启后消失，做出来是假承诺。公网实例所有访客共享一份数据，仅适合演示。
2. **公网数据是临时的**：`{TMPDIR}/fenglin-cloud-interview/fenglin.sqlite`，重启、重新部署或平台清理即清空。本地开发是持久的。
3. **导出说明**：简历 / 复盘 / 题库可导出 Markdown、Word（docx，服务端用纯 JS `docx` 库生成）与打印视图存 PDF；求职档案另有封面 + 5 个章节的 A4 打印视图（实际约 4 页）。均未引入 PDF 生成库，PDF 由浏览器「另存为 PDF」完成。
4. **PDF / 图片导入**：电子版 PDF 用 pdf.js 在浏览器本地抽文字；扫描件渲染成图片后交给智谱 `glm-4v-flash` 识别，识别失败可重试或手动填写。单文件 ≤10MB，扫描件最多前 3 页。
5. **语音作答依赖浏览器 Web Speech API**：Chrome 可能把音频交给浏览器厂商的识别服务（与应用无关）；不支持的浏览器自动降级为文字并提示。
6. **语音朗读依赖浏览器语音包**：使用 `speechSynthesis`，中文语音优先；系统没有中文语音时不朗读英文顶替，而是禁用按钮并提示静默降级。朗读与语音输入互斥，开始输入或录音会自动停止朗读。
7. **JD 抓取不是万能**：服务端仅抓取公开 http/https 页面，限制 3 次重定向、10 秒、1.5 MB，并校验 DNS 拒绝内网 / 回环；仍无法彻底防 DNS rebinding，纯 JS 渲染、需要登录或被反爬的页面会如实失败，需手动粘贴。
8. **常见题不是官方真题**：60 道题为本项目整理的社区常见题型与通用高频题，界面与数据均标注来源，不含「公司名 + 年份」出处，也不代表任何公司的招聘标准。
9. **数据备份是单实例迁移工具**：不做账号同步；JSON 文件含简历正文等敏感信息，需自行保管。当前导出格式为 v2（含投递阶段历史等），导入兼容 v1；文件损坏或版本不符会整份拒绝，合并模式会保留现有数据并追加副本（题库按题面去重），覆盖模式仍需先导出备份才可执行、且不可撤销。
10. **模型回复质量与耗时受网络影响**：出题 1–7 秒，单题反馈 5–17 秒，建议与报告 8–30 秒（单次上限 55 秒）；失败会提示重试或走本地降级，不会白屏。
11. **异步任务仍按单实例设计**：任务状态已落 `ai_job` 表（10 分钟过期），重启后可继续轮询；但不做多实例共享或跨实例调度，重启瞬间正在执行的任务会中断，需要重新触发。成长与档案的聚合缓存同样只在进程内，重启即空。
12. **限流只在单实例内计数**：按 IP 的分钟阈值与每日总量都在进程内存里，多实例部署时各实例各算一份，实际额度会成倍放宽；需要全局限流应在平台网关层做。
13. **线上静态资源长缓存未生效**：应用层对 `/assets/*` 设置了 `immutable`，本地同代码验证生效；线上响应头被平台 CDN 网关（volc-dcdn / Trae Hecate Gateway）改写为 `Cache-Control: no-store`，重复访问不会命中长期缓存。这是平台侧限制，应用层无法覆盖。
