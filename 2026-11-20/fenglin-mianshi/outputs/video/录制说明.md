## 四、旁白选择

**本版为静音轨**：MP4 内含一条 AAC 静音音轨（44.1 kHz 立体声），方便后续直接替换真人配音，同时保证播放器兼容性。

另出一版**机器合成旁白**：`丰麟云面-演示视频-旁白版.mp4`（Windows SAPI5 / `Microsoft Huihui Desktop` zh-CN，Rate 0、Volume 100，旁白为主声道并按 -16 LUFS 归一）。原静音版与 `.srt` 均未改动，逐段旁白文本、时间码与参数见 `旁白稿.md`。

替换真人配音的建议命令（保留已烧录字幕）：

```bash
ffmpeg -i 丰麟云面-演示视频.mp4 -i voiceover.wav \
  -map 0:v -map 1:a -c:v copy -c:a aac -b:a 160k -shortest \
  丰麟云面-演示视频-配音版.mp4
```

如果后续要改用外挂字幕而不是硬字幕，可直接使用同名 `.srt`；重新烧录时使用：

```bash
ffmpeg -i 丰麟云面-演示视频.mp4 -vf "ass=subs.ass" -c:v libx264 -crf 20 -c:a copy out.mp4
```

## 六、实拍说明与替代方式（如实披露）

1. **报告分镜**：示例档案里的三场面试只有分数，没有持久化的报告正文。为了让报告页有真实内容，拍摄期间通过站点自身的 API 在同一线上实例新建了一场面试，逐题提交真实作答并调用模型生成报告（总分 72），再录制该报告页。报告为模型真实生成，不是预写结果；录完后临时面试已删除。
2. **从简历生成面试题**：画面拍到的是「简历 + 常见题」的实际创建流程与来源说明；产品第一题固定为自我介绍，因此屏幕上首先出现的是引导题，后续轮次才按简历追问。这一点在字幕里没有夸大为「第一题就是简历题」。
3. **JD 匹配**：画面演示的是直接使用目标岗位 JD 进行分析；「贴公开招聘页链接代抓正文」是页面能力说明，录制中没有实际抓取外链，避免演示受目标站点反爬影响。
4. **求职档案 PDF**：训练台的 PDF 入口会新开标签页，录屏无法在同一视频流中捕获新标签，因此该段直接在同一页打开 `/print/profile` 打印视图并滚动展示，未伪造点击动作。
5. **今日复习**：点击「有点模糊」会真实改写该题的复习排程。录制结束后已通过 `demo/clear` + `demo/load` 恢复示例数据（18 条，含 3 条投递），临时面试已删除，线上示例状态与录制前一致。
