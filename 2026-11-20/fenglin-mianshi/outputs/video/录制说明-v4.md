## 四、与脚本或线上实际的差异（按线上实际录）

1. **首页今日计划数量**：脚本写「今天 0/1 已完成 · 本周共 7 条」；线上实际为「今天 0/3 · 本周共 21 条」（示例档案 + 已有面试生成的训练任务）。镜 02 勾选后为 1/3，镜 14 仍是 1/3。字幕避免写死总数，只保留「今天只做一件事」「勾掉今天这条」。
2. **7 天计划页任务数**：页头仍是「训练计划 · 7 天 / 每天最多 3 条」，但实际本周任务 21 条（7 天 × 3），不是脚本示例的 7 条；旁白按「每天最多三条」描述。
3. **模板页按钮与文案**：线上为「保存并去优化」，保存成功 toast 为「初稿已保存，正在打开简历优化」；脚本写「生成初版简历」。录制时先填 4 个必填栏（基本信息 / 教育背景 / 项目经历 / 专业技能），再做「AI 润色初稿」，最后点「保存并去优化」。
4. **分镜 04 的简历上下文**：为演示「应用到草稿 → 撤销应用」，该镜使用示例简历的建议列表；新建的「林知远 · Java 后端实习（初稿）」在前几次试拍中已应用过建议，重录时不再出现「应用到草稿」按钮。因此镜 04 顶栏简历名为「示例-林知远 · 后端实习简历」，与镜 03 保存的草稿名不同；旁白未提简历名。这是本次录制唯一一处跨镜上下文不一致，特此说明。
5. **JD 抓取字数**：国家大学生就业服务平台页面实际抓取 **427 字**，弹窗提示「请核对后再保存，未写入数据库」；脚本中的 N 字为占位。

## 七、复现方式

录制与合成脚本在临时目录 `%TEMP%\fenglin-v4\`（不进入仓库）：

- `record-v4.cjs`：按分镜录制真实浏览器操作（逐镜 webm，页面内鼠标叠加层）。
- `record-extra.cjs` / `record-08b-logo.cjs`：移动端、骨架屏、反问轮插入、结尾 LOGO。
- `build.cjs`：按分镜裁剪/变速、ASS 硬字幕、Huihui 旁白、混音与响度归一、最终编码。
- `tts.ps1`：System.Speech 中文语音合成。
- `cleanup.cjs`：录制数据清理与示例重载。

常用校验命令：

```
ffmpeg -hide_banner -i 丰麟云面-演示视频-v4.mp4
ffmpeg -hide_banner -nostats -i 丰麟云面-演示视频-v4.mp4 -map 0:a -af "ebur128=peak=true" -f null -
node check-srt.cjs  # 校验条数、起止、重叠
```
