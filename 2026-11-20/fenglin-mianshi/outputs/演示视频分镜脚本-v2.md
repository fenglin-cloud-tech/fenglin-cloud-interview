## 二、分镜详表

### 镜 01 · 0:00–0:12（12s）｜开场：成长曲线与三维雷达

- **画面与操作**：打开首页 `/`，不滚动。画面停在「能力成长」卡片：左侧总分趋势（3 个点 58 / 71 / 82，横轴为面试日期），右侧三维雷达（结构 75、内容 79、表达 77），下方图例「近期 · 最近 2 场 / 早期 · 前 1 场」。鼠标从趋势线缓慢移到雷达，不点击。
- **字幕**：「三场真实评分：58 → 71 → 82」
- **旁白**：「先看结果。同一个岗位练了三场，58、71、82，趋势和雷达都来自每场报告的真实评分。只练过一场时，这里只显示单场分数，不会硬画一条线。」
- **录屏注意**：必须先点首页演示数据条的「载入示例档案」，此时状态为「已载入示例档案：3 场面试 · 5 道题 · 3 条复盘」；空库只会显示「还没有已完成的面试」。停留 3 秒再移鼠标，给后期留字幕空间。只有单个岗位分组时不会出现岗位切换标签，属正常。

### 镜 02 · 0:12–0:22（10s）｜闭环清单与数据矩阵

- **画面与操作**：向下滚一屏，依次掠过数据矩阵（简历 1 / 目标岗位 1 / 完成面试 3 / 题库沉淀 5 / 复盘 3）、「闭环清单」六项全勾（有一份简历、有目标岗位、做过 JD 匹配诊断、跑完一场模拟面试、题库里有题、写过复盘）、当前上下文「示例-林知远 · 后端实习简历 / 示例-后端开发工程师（Java）」。
- **字幕**：「六步闭环，缺一环就卡住下一步」
- **旁白**：「这说明数据是打通的：简历、岗位、匹配、面试、题库、复盘，每一步的结果都会喂给下一步。接下来用模板再起草一份，专门投新岗位。」
- **录屏注意**：滚轮匀速，别停在「最近的面试」列表超过 2 秒，避免和后面报告镜头重复。清单里的「去完成 →」链接此时不应出现（六项已全勾）。

### 镜 03 · 0:22–0:50（28s）｜模板库：起草一份新简历

- **画面与操作**：
  1. 左侧导航点「模板库」；画面出现四张模板卡：技术研发、产品经理、运营 / 内容、数据分析。
  2. 点「技术研发」卡片上的「按引导填写」，进入 `/templates/tech`。
  3. 左侧栏位切换：基本信息 → 教育背景 → 项目经历。停在「项目经历」：上方是「这栏写什么」的问题提示，中间是输入框，下方并排「✓ 建议这样写 / ✕ 别这么写」正反例。
  4. 在输入框补一段项目描述（录制时可粘贴后 2× 加速）。
  5. 右侧「实时预览」同步出现文字；点一次「AI 润色初稿」，等结果出来（加速）。
  6. 点左下「生成初版简历」，toast 提示「初稿已保存，正在打开简历优化」，自动进入 `/optimize?resumeId=…`。
- **字幕**：「四套岗位模板，每栏都有正反例」→「生成初版，自动进优化」
- **旁白**：「没有简历也能开始。模板不是让你照抄，是告诉你这一栏先写什么、长什么样；写不下去可以先用 AI 润色，生成后直接带着这份简历进优化。」
- **录屏注意**：四套模板的板块数不同（技术研发 6 栏，含「实习经历」「校园经历 / 荣誉」两个可选栏），别口播成「每套都是六栏」。AI 润色要真实等待，后期加速并加「加速」角标。若不想等润色，可只录正反例和实时预览，旁白保留一句带过。

### 镜 04 · 0:50–1:10（20s）｜简历优化：逐条批注

- **画面与操作**：进入 `/optimize`。画面先给三栏工作台：01 JD、02 原稿、03 建议。点「逐条批注」页签，再点 03 栏的「生成修改建议」；出现进度条（通常 20–40 秒，后期 4× 加速）。结果出来后：总体判断卡片 → 各板块卡片 → 展开一条建议，鼠标停在「为什么改」和「措辞 / 量化 / 结构 / 冗余」标签上。
- **字幕**：「每条建议都说清『为什么改』」
- **旁白**：「它不是泛泛夸你写得好，而是按板块指出问题：是措辞、缺量化、结构顺序还是冗余，并且只改写法，不替你编数据。」
- **录屏注意**：右上角状态需为「MODEL · 在线」；若显示「本地降级」，简历建议会返回 503 提示，不能作为主镜头。建议等待段不要剪掉，保留 2 秒真实等待画面再加速。

### 镜 05 · 1:10–1:26（16s）｜目标岗位：招聘链接抓 JD

- **画面与操作**：
  1. 左侧导航点「目标岗位」，点右上「新建岗位」。
  2. 弹窗内填岗位名称「Java 后端实习」，公司可留空。
  3. 在「从招聘页面抓取」输入框粘贴一个公开招聘页链接，点「解析链接」。
  4. 成功后出现绿色提示：「已抓取《…》 N 字……未写入数据库」，旁边有「撤销替换」；下方「JD 原文」已填入正文。
  5. 点「保存」，回到岗位列表；在该卡片点「设为当前」，再点「做匹配分析」进入优化页。
- **字幕**：「贴链接抓 JD，抓完还能改」
- **旁白**：「JD 不用手抄。贴一个公开招聘页链接，服务端代抓正文，先告诉你抓了多少字，确认后才保存；抓不到会说明原因，原来的 JD 不会被清掉。」
- **录屏注意**：这是**唯一**的 JD 抓取入口，不在 `/optimize`。提前准备可公开访问的招聘页；若现场失败，保留失败提示（如「页面不存在或已下线（HTTP 404）」）也能用，旁白改说「失败会保留原输入」，但主链仍要用一份可用的 JD 继续。抓取有 10 秒超时，别连点。

### 镜 06 · 1:26–1:46（20s）｜JD 匹配：到底缺什么

- **画面与操作**：在 `/optimize` 点「JD 匹配」页签，点「开始匹配分析」（通常 10–30 秒，加速）。结果区依次展示：匹配度圆环 → 红色「缺 xxx」关键词 → 覆盖对照表（岗位要求 / 状态 / 简历证据，状态为已覆盖、部分覆盖、缺失）→ 「补齐动作」列表。鼠标沿表格逐行下滑。
- **字幕**：「匹配分 + 缺失关键词 + 覆盖对照表」
- **旁白**：「匹配不是给个分就完：每条要求都对着简历找证据，标成已覆盖、部分覆盖或缺失，缺的关键词单独列出来，再给补齐动作。」
- **录屏注意**：同一份简历多次匹配会进「历史诊断」，镜头里可停在历史卡片 1 秒，说明可对比多次投递，但不要展开。表格较长，滚动速度放慢，确保「部分覆盖」这一行能看清。

### 镜 07 · 1:46–1:57（11s）｜对话迭代与导出

- **画面与操作**：切到「对话迭代」页签，在输入框输入「把项目经历改得更量化，突出我负责的后端部分」，点「发送」。等回复与右侧「当前版本」更新；点「对比原始」，画面出现绿色新增 / 红色删除的行级 diff。随后切「导出」页签，鼠标停在「下载 .md / 下载 Word（.docx） / 打印 / 存为 PDF」三个按钮上，点一下「下载 Word（.docx）」。
- **字幕**：「改完看行级差异，定稿导 Word」
- **旁白**：「不满意可以继续说，改稿和差异都摆在旁边；定稿导出 Word，或者走打印视图存 PDF。」
- **录屏注意**：Word 与打印视图读的是**已保存**版本；本镜的简历来自模板生成，已保存，可以直接导出。若现场改了正文，先点「另存新版」再导出，否则会导出旧版。

### 镜 08 · 1:57–2:13（16s）｜新建面试：四种出题方式

- **画面与操作**：进入 `/interviews`。左侧「新建面试」卡：使用简历选刚生成的这份，目标岗位选「Java 后端实习」。依次点四个分段按钮「只用简历题 / 简历 + 常见题 / 只用常见题 / 从题库再练」，每个停 1 秒。停在「只用常见题」时，展示下方「常见面试题 · 按岗位方向」面板：来源说明「社区常见题型整理 / 通用高频题 · 共 60 题」，方向下拉「后端开发（12 题）」，以及 3 道示例题（技术基础 / 项目深挖 / 行为面试）。最后点回「简历 + 常见题」，点「开始面试」。
- **字幕**：「简历 + 岗位生成题目」→「60 道常见题，来源写清楚」
- **旁白**：「出题可以只用简历，也可以混入常见题。这 60 道按五个方向整理，界面写清来源是社区常见题型，不是任何公司的真题。这场我们混着来。」
- **录屏注意**：常见题面板里的来源说明要拍清楚，这是作品诚实性的关键。点「开始面试」会真实创建一场（面试 C）；也可以只做悬停不点击，直接切到面试 B 的会话画面。

### 镜 09 · 2:13–2:49（36s）｜考场：朗读、限时、反馈、追问

- **画面与操作**（按顺序，每步停 2–3 秒）：
  1. 进入会话页。顶部是轮次轨道（自我介绍 / 专业能力 / 行为面试 / 反问环节），右侧进度「第 壹 轮 · 自我介绍 · 1/1」。
  2. 题目卡：考察点、题干。点「▶ 朗读题目」，按钮变为「■ 停止朗读」，旁边显示「语速 1.0×」；点语速按钮切一次，再点停止。
  3. 右上「本题限时 01:00」倒计时；等到 00:29，计时变提醒色（后期可 4× 加速等待）。
  4. 作答区输入两三句（或点「🎙 语音作答」口述，需麦克风权限）；点「提交并看反馈」。
  5. 反馈卡出现：结构 / 内容 / 表达三个分数与进度条、「做得好的」「必须改」两栏、「改写示范」。
  6. 若出现「追问 1/2」与「下一题是追问（…）」，鼠标停在追问标签上（最多两层）。
  7. **插入 6 秒**：切到面试 B（「简历 + 常见题」）中带「常见题」标签的一题，展示题源说明与「加入个人题库」按钮，点一下，按钮变「已加入个人题库」。
- **字幕**：「最后 30 秒，计时变色」→「追问最多两层」→「常见题一键入个人题库」
- **旁白**：「题目能朗读，中文语音优先；每题按轮次限时，最后 30 秒变色，到点只提交已经写下的内容，空着不会替你编。答完立刻给三维反馈，分数不够会追一问，最多两层。」
- **录屏注意**：
  - 限时按轮次不同：自我介绍 60 秒、专业能力 150 秒、行为面试 120 秒、反问 90 秒。别口播成统一 60 秒。
  - 朗读依赖系统中文语音包；没有中文语音时按钮会禁用并提示，**不要**用英文语音硬读。
  - 到点自动提交只在有有效内容时发生；空内容会提示未提交。
  - 追问不是每题都有，取决于分数；建议在同岗位再开一场「简历 + 常见题」，故意答得笼统一些，答到出现追问与常见题为止，用它补拍第 6、7 步。
  - 「加入个人题库」只出现在常见题反馈卡上；第 7 步的 6 秒素材来自同一岗位的另一场，剪辑时不要加"同一场"字样。

### 镜 10 · 2:49–3:02（13s）｜面试报告

- **画面与操作**：打开面试 C 的 `/interviews/:id/report`。画面：总分圆环、各轮得分条、「薄弱环节」「建议复习点」两栏、「下一步」三个按钮（生成复盘草稿 / 去题库 / 再来一场）、「逐题记录」折叠列表。展开一条，露出当题的三维小分与改写示范。
- **字幕**：「一场结束，薄弱环节直接点名」
- **旁白**：「整场结束生成报告：总分、各轮得分、薄弱环节和建议复习点；逐题记录还能展开，看当时那题到底差在哪。」
- **录屏注意**：报告只有在所有轮次答完或主动结束后才生成；录制时用预置的已完成场次，不要现场从头答完。报告页右上还有「复制报告 / 下载 .md」，镜头不需要点。

### 镜 11 · 3:02–3:15（13s）｜一键复盘

- **画面与操作**：在报告页点「生成复盘草稿」，toast 提示「已生成 N 条复盘草稿，去补改进点」，自动跳到 `/reviews`。画面停在复盘卡片：题目、岗位标签、星级、「我的回答 / 实际表现 / 改进点」三段、底部「编辑 / 加入题库 / 删除」；有标签时右下角会显示标签文本。
- **字幕**：「面试 → 复盘草稿，补上改进点」
- **旁白**：「报告页可以把整场面试变成复盘草稿，题目、你的回答和反馈要点都带过来，补上改进点，它就成了一条能复习的记录。」
- **录屏注意**：这一步会真实写入复盘记录；重拍时点首页「重新载入示例」恢复干净状态。别点「AI 帮我想改进点」，它会消耗模型时间且不是本镜重点。新生成的复盘不一定带标签，别指着标签念示例文案。

### 镜 12 · 3:15–3:35（20s）｜记忆曲线与再练

- **画面与操作**：
  1. 进入 `/bank`，顶部卡片「记忆曲线 · 今日待复习」：显示「N 道题到期」与「M 道已逾期」（示例档案当前为 7 道到期、2 道逾期），说明间隔档位 1 / 3 / 7 / 14 / 30 天。
  2. 点「开始复习」，弹窗「今日复习 · 第 1 / N 题」：复盘自评星级、逾期天数、「上次的回答」「改进点」。
  3. 点「有点模糊」，出现结果「下次复习：某日期（N 天后 · 第 X 档）」；点「下一题」再停 1 秒，然后「关闭」。
  4. 回到题库列表，勾选 2 道题，底部出现「已选 2 道」，点「开始再练」（或顶部「再练选中的 2 道」）；画面进入新会话后立即切走。
- **字幕**：「今天该复习什么，直接列出来」→「记住了升档，没记住回到 1 天」
